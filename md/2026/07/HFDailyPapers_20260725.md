## 智能体自主推理与自我改进

该方向的研究重点在于如何通过递归机制提升智能体在复杂任务中的表现。AREX [AREX: Towards a Recursively Self-Improving Agent for Deep Research](https://arxiv.org/abs/2607.21461) 提出了一种递归自我改进（RSI）框架，通过内外循环交替执行证据收集与约束审计，利用压缩上下文状态引导后续研究，旨在解决发现成本高而验证成本低的不对称性问题。样本效率方面，Experience Distillation [Sample-Efficient Learning from Agent Experience](https://arxiv.org/abs/2607.21051) 结合在线学习与上下文蒸馏，在无额外环境交互的情况下保留了多数In-Context Learning的收益，显著降低了环境采样成本。然而，现有模型在动态场景中仍存在局限，LLMs Get Lost in Evolving User Intent [LLMs Get Lost in Evolving User Intent](https://arxiv.org/abs/2607.20734) 指出，当前大语言模型在用户意图演变的对话中难以忠实追踪和响应变化，揭示了静态评估与动态协作需求之间的差距。此外，NVIDIA Object-Oriented Agents (NOOA) [NVIDIA-labs OO Agents: Native Python Object-Oriented Agents](https://ar分析表明，递归自我改进通过结构化地管理验证状态和上下文压缩，为长期复杂推理提供了新范式；经验蒸馏技术则证明了将短期记忆转化为长期参数优化的潜力，有助于降低多智能体训练的算力门槛。

## 具身智能、机器人导航与操控

具身智能领域侧重于提升机器人在物理世界中的感知、导航和操作能力。TableVerse [TableVerse: A Large-scale Tabletop Dataset with Real-world Grounded Layouts for Generalizable Manipulation](https://arxiv.org/abs/2607.21017) 构建了一个包含10万场景的大规模桌面数据集，通过从真实图像反推物理一致的仿真环境，解决了传统生成方法缺乏物理合理性及密集杂乱场景模拟不足的问题。在导航方面，Robostral Navigate [Robostral Navigate](https://arxiv.org/abs/2607.20785) 仅依赖单目RGB视频流预测航点，通过前缀缓存训练技术和树状注意力掩码，实现了跨不同机器人形态（轮式、足式、无人机）的可扩展部署，并在R2R-CE和RxR-CE基准上创下新高。视觉跟踪方面，ReferTrack [ReferTrack: Referring Then Tracking for Embodied Visual Tracking](https://arxiv.org/abs/2607.20061) 引入“先指认后跟踪”范式，结合时间视角边界框指示符，在单摄像头设置下提升了具身视觉跟踪的成功率。OpenForgeRL [OpenForgeRL: Train Harness-native Agents in Any Environment](https://arxiv.org/abs/2607.21557) 则提供了一种训练基于特定推断枢纽（Harness）的智能体的开源框架，通过在Kubernetes中解耦训练与推理，实现了在复杂工具使用和多模态GUI环境中的端到端强化学习。分析显示，从数据生成的真实性（TableVerse）到控制接口的标准化（NOOA/OpenForgeRL），以及感知模块的轻量化（Robostral Navigate），具身智能正朝着更通用、更易训练和更低硬件依赖的方向演进。

## 视频生成与动态内容理解

视频生成技术正致力于提高生成质量、时空一致性及可控性。SANA-Video 2.0 [SANA-Video 2.0: Hybrid Linear Attention with Attention Residuals for Efficient Video Generation](https://arxiv.org/abs/2607.21553) 提出混合线性注意力架构，结合门控线性注意力和周期性软最大锚点，在保持长序列线性缩放优势的同时恢复了全秩标记交互，实现了单GPU高分辨率高效视频生成。WorldWeaver (W^2) [Streaming Multi-Agent Autoregressive Diffusion Model with World State Registers](https://arxiv.org/abs/2607.21594) 针对多智能体视频生成，引入了可学习的世界状态寄存器，用于跨代理和维护全局一致性，显著改善了逻辑连贯性。GraphVid [GraphVid: Interactive Graph-Controllable Video Generation](https://arxiv.org/abs/2607.21580) 则转向结构化控制，通过图条件指导图像到视频的生成，提供了比传统运动控制更精确的多主体交互操控能力。同时，对于视频内容的底层理解，Structured Dynamics Model (SDM) [Self-Supervised Learning of Structured Dynamics from Videos](https://arxiv.org/abs/2607.21576) 展示了如何从预训练视觉Transformer中提取结构化动态表示，有效分离相机运动与物体运动。分析表明，高效架构设计（SANA）、显式状态维护（WorldWeaver）及结构化语义接口（GraphVid）共同推动了视频生成向高保真、强控制和逻辑一致性的方向发展。

## 教育评估、代码智能与金融分析

针对特定垂直领域的基准测试与智能体应用正在深化。K12-KGraph [K12-KGraph: A Curriculum-Aligned Knowledge Graph for Benchmarking and Training Educational LLMs](https://arxiv.org/abs/2605.09635) 构建了基础教育知识图谱及相应基准，强调了课程认知（如先决关系、视觉定位）的重要性，并证实了领域特定监督能有效缩小大型语言模型在教育任务上的性能差距。Tencent WorkBuddy Bench [Tencent WorkBuddy Bench: A Multi-Domain Coding-Agent Benchmark with Contamination-Resistant Task Construction](https://arxiv.org/abs/2607.20911) 提出了抗污染的多领域代码智能体基准，通过逆向工程真实提交记录生成自然语言任务描述，涵盖了代码、前端、办公及安全四个维度。FinanceComplexQA [FinanceComplexQA: Benchmarking Agentic Reasoning on Industrial-grade Financial Documents](https://arxiv.org/abs/2607.19238) 则聚焦于工业级金融文档的深度研究，评估智能体在处理复杂布局和多跳推理方面的能力。分析指出，这些研究反映了对垂直领域智能体在结构化知识遵循（教育）、工程真实性（代码）和专业深度推理（金融）方面的迫切需求，且评估方法正向抗污染、多模态和高复杂度迈进。

## 模型训练优化与评估方法论

在基础模型训练与评估层面，多项研究提出了更高效或更准确的技术路径。Visual Contrastive Self-Distillation (VCSD) [Visual Contrastive Self-Distillation](https://arxiv.org/abs/2607.21556) 通过移除图像内容与纯文本输入的条件差异来生成自蒸馏信号，无需外部教师或特权答案即可提升视觉语言模型的性能。Multi-Turn On-Policy Distillation with Prefix Replay (ReOPD) [Multi-Turn On-Policy Distillation with Prefix Replay](https://arxiv.org/abs/2607.04763) 解决了多轮Agent任务中在线蒸馏的高成本问题，利用预收集的轨迹作为回放前缀，实现了零工具调用的离线蒸馏。Dataset Distillation by Influence Matching [Dataset Distillation by Influence Matching](https://arxiv.org/abs/2607.16859) 从结果对齐的角度出发，通过样本级影响估计器匹配完整数据集对最终参数的影响，超越了传统的过程匹配方法。Predictive Divergence Masks for LLM RL [Predictive Divergence Masks for LLM RL](https://arxiv.org/abs/2607.10848) 改进了大模型强化学习中的信任区域掩码，使用预测散度替代基于采样Token重要性比率的方法，提高了更新的稳定性。ProVisE [Show, Don't Tell: Evaluating Spatial Cognition in Generative Pixels Rather Than LLM Text](https://arxiv.org/abs/2607.21072) 建立了空间认知评估的新协议，允许图像生成模型直接在像素空间展示空间判断，从而弥合了与文本输出模型在评估标准上的差异。Color Pass-Through [Color Pass-Through via Camera-Display Coupling](https://arxiv.org/abs/2607.12746) 则将相机与显示器视为耦合系统进行端到端校准，提升了色彩还原度。Recurrent Sinusoidal INRs [Recurrent Sinusoidal INRs for Efficient High-Fidelity Representation](https://arxiv.org/abs/2607.21485) 利用正弦激活的谐波频谱特性，通过递归迭代提升隐式神经表示的保真度。这些工作共同表明，训练方法的优化正趋向于去中心化依赖（如自蒸馏、离线回放）、结果导向对齐（如影响匹配）以及更精细的信任域控制。
