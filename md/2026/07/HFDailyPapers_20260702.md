# 每日HFDailyPapers-2026年06月30日

## 智能体记忆与可靠性
近期研究开始关注长期记忆对大语言模型（LLM）智能体行为的潜在负面影响，特别是记忆可能诱导的谄媚问题。[MemSyco-Bench](https://arxiv.org/abs/2607.01071) 提出了一个全面的基准测试，用于评估智能体系统中由记忆诱导的谄媚现象。该基准测试旨在衡量智能体何时应受记忆影响决策，以及如何有效使用有效记忆，其评估覆盖拒绝记忆作为事实证据、遵守其适用范围等五个关键任务。相关资源已在社区开源。分析表明，随着智能体从单轮助手向长期协作者演进，确保其记忆系统不仅存储和检索正确，更能支持客观推理，是构建可靠智能体的关键挑战。

## 视觉与多模态推理
多项工作致力于提升模型的精细视觉推理能力，核心思路是将感知过程与逻辑推理过程解耦。[Perceive-to-Reason (P2R)](https://arxiv.org/abs/2607.01191) 提出一个统一框架，模型先作为“感知器”定位问题相关证据，再作为“推理器”回答问题，并引入了强化学习策略以更好地对齐训练。[PixelEyes](https://arxiv.org/abs/2607.00115) 则构建了一个多轮视觉推理智能体，显式地将推理与感知分离，利用分割模型提供精确的掩码定位，并采用广度优先搜索策略探索语义区域，以解决多轮推理中轨迹冗长的问题。[Multimodal Continuous Reasoning via Asymmetric Mutual Variational Learning](https://arxiv.org/abs/2607.00461) 针对多模态大语言模型（MLLM）将复杂视觉推理压缩至离散词元时损失感知细微差别的问题，提出了不对称互变分学习（AMVL）框架，通过双向校准目标解决了连续潜变量推理中的训练-推理不匹配问题。此外，[SciIR](https://arxiv.org/abs/2606.30124) 针对科学图像生成领域，提出了一个受皮尔斯符号三元组启发的综合资源，旨在通过大规模数据集和新的评估基准来提升模型的科学推理能力。分析显示，这些工作共同表明，明确区分或优化感知与推理的交互机制，是突破当前多模态模型在细粒度理解与复杂推理任务上性能瓶颈的有效路径。

## 大模型训练与优化
围绕大模型训练效率与效果的研究持续推进，方法涵盖数据配方、模型架构与训练流程自动化。[CausalMix](https://arxiv.org/abs/2607.01104) 将大语言模型训练中的数据混合优化问题转化为因果推断问题，通过在小模型上拟合因果模型来估计条件平均处理效应，从而动态推断最优数据混合策略，并成功将其泛化至更大模型和长链思维数据。[The State-Prediction Separation Hypothesis](https://arxiv.org/abs/2607.01218) 提出了一种假设，即分离Transformer中用于存储状态和预测下一个词元的两个功能可能带来更好性能。研究者设计了一种具有两个计算流的Transformer变体，实验表明该设计能提供更好的数据和计算效率。[AutoTrainess](https://arxiv.org/abs/2606.31551) 则致力于实现语言模型训练的自主化，它是一个LM智能体，将规划、数据准备、训练、评估和日志记录等操作封装为智能体-计算机接口，并通过外化人类经验的工作流和规则来引导智能体实现有效可靠的训练行为。分析表明，无论是从数据层面利用因果推断挖掘最优配方，还是从架构层面探索功能解耦，或是从流程层面实现自动化，这些研究均旨在突破当前大模型训练所面临的扩展性与可控性限制。

## 具身智能与机器人
具身智能领域的研究聚焦于提升机器人在动态环境中的泛化能力与任务复杂度。[Domain Arithmetic (DART)](https://arxiv.org/abs/2607.00666) 针对视觉-语言-动作（VLA）模型在环境偏移下性能下降的问题，提出一种基于权重向量算术的一次性适应方法。该方法仅需单一示范即可完成对目标域的适应，并通过对奇异分量进行子空间对齐来准确隔离域特定信息。[ABot-M0.5](https://arxiv.org/abs/2607.00678) 提出了一种新的世界动作模型，专门针对移动操作任务，通过引入中间潜在动作、设计双层混合专家架构以及提出梦境强迫训练策略，在时间粒度、动作空间和推理条件三个层面上实现对齐。[ASPIRE](https://arxiv.org/abs/2607.00272) 是一个持续学习系统，能够自主编写和优化机器人控制程序，并将经验积累为可重用的技能库，其技能可在任务、仿真与真实环境及不同机器人形态间迁移。[Valdi](https://arxiv.org/abs/2607.00917) 则探索了将扩散模型用作世界模型以支持模型预测控制，通过端到端在线训练结合潜在扩散动力学模型，在初步实验中展示了可行性。分析表明，这些工作分别从快速适应、任务对齐、技能持续学习和不确定性建模等不同角度，推动着机器人智能体向更自主、更鲁棒的方向发展。

## 多模态与科学应用
面向科学发现和专业领域的多模态应用正在兴起。[BioInsight](https://arxiv.org/abs/2606.20997) 是一个用于生物医学知识发现的多智能体系统，它超越了静态报告生成，能够组织特定疾病的证据并生成交互式界面，使研究人员可以主动检查证据、评估不确定性并精炼假设。[Graph-Native Reinforcement Learning Enables Traceable Scientific Hypothesis Generation](https://arxiv.org/abs/2607.00924) 为加速材料发现，开发了图原生推理模型Graph-PRefLexOR，通过强化学习将推理组织为机制探索、图构建等明确阶段，从而生成可追溯的科学假设，在材料科学问题上实现了显著的性能提升和更好的推理可追溯性。[AtomiMed](https://arxiv.org/abs/2606.31292) 提出了一个通用的、模态无关的评估框架，用于评估医学报告生成的质量。它通过将复杂的医学叙述分解为标准化的多层级原子临床事实，并模拟多放射科医生同行评审过程来验证临床一致性。分析表明，这些应用通过引入结构化推理、交互式验证或细粒度评估框架，致力于解决领域专家对AI系统可靠性、可解释性和实用性的核心关切。

## 其他动态
**模型评估与鲁棒性**：[PerceptionRubrics](https://arxiv.org/abs/2606.28322) 提出了一个基于量规的评估框架，旨在校准多模态评估以适应人类感知，其设计的门控评分机制能在关键视觉事实失败时触发严格惩罚，实验揭示了模型在密集领域中的可靠性缺口。[Cross-Domain Generalization Failure in Lightweight Intrusion Detection Models](https://arxiv.org/abs/2607.00553) 研究发现，为IIoT网络设计的轻量级入侵检测模型在跨网络评估时表现不佳，表明其可能依赖于粗糙的端口类别特征等捷径，研究强调应采用跨网络评估来检验部署就绪性。[When LLMs Read Tables Carelessly](https://arxiv.org/abs/2606.32029) 首次系统评估了表格数据引用错误（DREs），并证明将数据引用作为批评者机制可以显著提升答案准确性。

**模型与系统发布**：[Seed2.0 Model Card](https://arxiv.org/abs/2607.00248) 发布了一个旨在解决复杂现实世界任务的模型系列，其通过构建基于真实需求的评估系统，着重改善长尾知识和复杂指令遵循能力，以提升模型在长周期任务中的可靠性。[TurboServe](https://arxiv.org/abs/2606.19271) 是首个专门为流式视频生成工作负载设计的服务系统，通过在线调度算法协调会话放置和GPU资源调配，以应对会话时长异质性和用户需求时变性挑战，在延迟和成本上均优于基线配置。

**应用方法与跨领域**：[CogSENet](https://arxiv.org/abs/2606.30030) 受鹰的视觉系统启发，提出了一个动态的、语义对齐的图像复原框架，用于解决盲图像去模糊问题，在处理空间变化退化时展现出优势。[NoPA](https://arxiv.org/abs/2607.00529) 提出使用非参数分布表示物体，以改进在线实时三维场景图生成，解决了参数化高斯表示带来的几何细节损失和合并不准确问题。[AI translation of literary texts](https://arxiv.org/abs/2606.26040) 通过让读者进行沉浸式和细读比较，发现尽管机器翻译“尚可”，读者在整体上仍更偏爱人工翻译的易读性、清晰度和沉浸感，自动指标未能捕捉到这种读者偏好。[SPIRE](https://arxiv.org/abs/2607.00407) 将幻灯片个性化制定为逆规划问题，通过结构去噪和多智能体强化学习来学习潜在的设计意图，以解决现有方法难以捕捉细粒度页面级设计意图的难题。[DiscoPER](https://arxiv.org/abs/2607.01131) 是一个由大语言模型驱动的自主科研框架，它通过迭代元反思机制，动态生成并执行代码来探索数据集，旨在进行开放式的科学发现，在生态学知识基准测试中验证了其有效性。[Personalization as Inverse Planning](https://arxiv.org/abs/2607.00407) 提出了SPIRE框架，通过学习潜在设计意图来实现幻灯片生成的个性化。
