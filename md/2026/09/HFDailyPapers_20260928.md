

# 每日HFDailyPapers-2026年09月28日

## 长上下文与注意力效率

针对语言模型长上下文扩展中自注意力二次计算成本的瓶颈，[PISA](https://arxiv.org/abs/2609.31093) 提出了一种金字塔 Top-K 选择策略的块稀疏注意力机制。该方法构建从粗到细的键层次结构，在每层使用 LogSumExp 评分逐步筛选候选，最终实现 O(N log N) 的时间复杂度，而非传统方法的二次复杂度。配合硬件感知的 Triton 核融合层次路由与评分过程，避免了查询-键分数矩阵的显式物化。在语言建模任务上的评估显示，该方法在常识推理基准上与基线持平，同时在检索任务上表现更优。分析表明，将注意力块选择从评分所有查询-块对转变为分层筛选，为长序列建模提供了可行的效率优化路径。

[Disaggregated Quantization](https://arxiv.org/abs/2609.26333) 则从量化角度优化 LLM 推理，提出将预填充（prefill）和解码（decode）阶段分别适配不同的计算格式与权重存储策略。在 Qwen 3 和 Gemma 3 上的实验表明，移除解码阶段的激活量化可在不影响推理成本的前提下提升解码密集任务的准确率；针对 NVFP4 预填充器的训练在 MMLU-Pro 上提升了 32.5 个点。结合从 SSD 流式传输权重的卸载方案（ODP），在 27B 模型上实现了 1.78 倍的首次 token 延迟加速。研究证实预填充与解码阶段对量化策略的需求存在本质差异，分离处理可释放进一步性能潜力。

[Depth-Adaptive Inference via Continuous Depth Batching](https://arxiv.org/abs/2608.09444) 解决了循环语言模型深度自适应推理中的批处理效率问题。该方法通过在循环步骤之间形成新批次，动态调度循环与非循环架构部分，管理循环 KV 缓存，并提前预测退出循环的 token 以实现异步批处理准备。在 Ouro 1.4B 和 Huginn 3.5B 上的实验显示，CDB 可实现最高 99% 的理论最大加速比，而全循环架构最适合深度自适应推理，因为循环核心外的大块非循环层（如 token 嵌入、LM head）会延缓调度并增加复杂性。

## 多智能体协作与评估基准

[AgentWorld](https://arxiv.org/abs/2609.31590) 引入了一种面向长程多智能体协作的基准测试，包含 100 个由人工标注的任务（另含 100 个增强变体），任务跨越 50+ 轮交互，要求在 MMORPG 沙盒环境中协调 3-20 个具有非对称角色与能力的智能体。该基准提出了因果协作有效性（CCE）指标，通过追踪智能体行动间的因果依赖关系量化团队协作贡献。在 Gemini 3 Flash、Claude Haiku 4.5、GPT-5 Mini 和 DeepSeek R1-70B 上的实验表明，最佳模型任务成功率仅为 52.0%，系统性地出现通信崩溃、角色混淆和跨轮计划维持失败等问题。该基准填补了现有评估多集中于短期竞争或独立性能聚合的空白，为长程协作能力研究提供了开放工具。

[Game Arena](https://arxiv.org/abs/2609.31473) 提出了 Kaggle Game Arena 平台，通过结构化竞技环境评估 LLM 的战略规划能力。与静态基准不同，该平台支持模型在头对头比赛中竞争，随着模型进化游戏难度自然上升以防止性能饱和。三个试点游戏环境（国际象棋、扑克、狼人杀）分别覆盖完全信息、不完全信息和多人博弈场景，支持系统性研究模型在不确定性下的战略规划、适应性与鲁棒性。平台基础设施强调可复现性、透明度以及对新游戏的可扩展性。

[TRACE](https://arxiv.org/abs/2609.30670) 针对流式视频理解提出了条件感知评估框架，明确标注证据有效性时间、视觉历史维持方式和响应触发机制。该框架结合时间审计视觉任务、证据时机和指令依赖触发注解，采用统一的核心-适配器协议控制信息可用性。对 517 个视频中的 1,240 条记录、八个模型配置的评估显示，相近的 QA 准确率可能掩盖完成度、答案有效性和生成工作负载的显著差异，而主动性能可细分为响应质量、延迟、误报和漏报等维度。研究主张流式视频性能应被理解为执行条件化系统行为而非单一分数。

## 机器人与具身智能

[InternW0-Δ](https://arxiv.org/abs/2609.31394) 提出了统一的世界动作模型（WAM），将大规模预训练模型的视觉动力学、场景语义、4D 几何和运动先验整合到机器人动作生成框架中。该方法采用混合 Transformer（MoT）架构，预训练视频专家与动作专家在冻结 VLM 的语义指导下交互，预训练 4D 基础模型通过仅训练蒸馏注入几何与运动先验。引入的因果印记（Causal Imprint）机制从仅训练的未来监督中学习未来相关场景变化，为动作专家提供预测表示而无需推理时的未来视频 rollout。基于超过 20,000 小时开放机器人演示数据的异质语料库预训练后，该方法在仿真基准和真实机器人平台上均优于先前的方法。研究计划开源训练代码、模型权重、基础设施、数据处理流程和可授权的处理数据。

[Morphometric Imitation](https://arxiv.org/abs/2609.28660) 提出三阶段框架将人类手-物体交互（HOI）转化为零样本 sim-to-real 视觉运动策略。首先，形态学优化（MMO）在保持接触点的同时跨手部形态进行运动运动学重定向；其次，残差强化学习利用对象位姿和接触信息精化动力学可行的机器人演示；最后将演示蒸馏为视觉运动策略。在三种机器人手和十个 HOI 上的实验显示，MMO 在接触 F1 上比最强基线提升至少 8 个点，下游动态重定向成功率提升最高 35 个点，最终视觉运动策略在 300 次真实世界实验中达到 89.3% 的零样本成功率。

[VLA-Precision](https://arxiv.org/abs/2609.04355) 针对预训练视觉-语言-动作（VLA）模型在高精度重复性任务中的不可靠性，提出了非对称协同自引导（ACoB）算法和 ACoB-Stream 架构。ACoB 在不同时间尺度上建立非对称协同自引导：早期通过行为干预指导快速提升策略性能，随着自主经验积累，全局回报传播与局部偏好排序逐步校准价值估计。ACoB-Stream 通过不变状态解耦和按需流式传输实现高达 10.9 倍的吞吐量和计算效率提升。在四类别九项高精度化学任务上的评估显示，VLA-Precision 在 45.8 分钟/任务内达到 98.3% 平均成功率，片段运行速度达到 VLA 和 RL 基线的 1.2 倍和 1.8 倍。

[Tactile-JEPA](https://arxiv.org/abs/2609.24385) 针对分布式电子皮肤触觉传感器稀疏不规则排列的特性，提出拓扑感知自监督预训练方法。该方法利用传感器连接图引导空间掩码，预测被掩码传感单元的嵌入，通过双尺度掩码同时捕捉局部接触细节和全局触觉表面状态。在涵盖磁性和压阻传感器、不同机器人形态和单/双传感器配置的三个数据集上的实验表明，Tactile-JEPA 较先前最先进方法将力估计误差降低 6.3%，手持定向误差降低 20.8%，并在策略学习等下游应用中保持一致增益。分析表明触觉感知的收益关键取决于编码器预训练质量。

## 表示学习、量化与压缩

[FuseReg](https://arxiv.org/abs/2609.31620) 针对表示自编码器（RAEs）中重构与生成阶段特征层选择的权衡问题，提出通过随机编码器层子集训练替代启发式层融合的正则化方法。理论分析表明，子集采样显式惩罚了跨层不一致的敏感性。在 ImageNet-256 上使用 DINOv3-L 的实验中，单个 FuseReg 解码器无需重新训练即可从完整、稀疏和单层融合中重构，PSNR 高于专门针对固定融合训练的解码器。解码器替换 Alone 使未引导 gFID 降低 27%，对 DiT-Base 联合正则化使 gFID 降低 29%。研究证明下游模型层融合鲁棒性训练可缩小重构-生成差距而无需修改预训练编码器。

[Softmax Reparameterization](https://arxiv.org/abs/2609.31291) 提出针对输出头的后训练重参数化方法以缓解大词表导致的量化失真。该方法对每行输出减去词汇行均值的标量倍数，并通过验证集 KL 散度为 RTN、激活加权 MSE 和全海森 GPTQ 分别选择系数。该方法保持全精度 softmax 分布且无需修改已训练解码器。在 Phi-4-mini 上，AW-MSE KL 从 0.936 降至 0.256，并在 W2 压缩压力测试下跨几乎整个模型-量化器矩阵展现收益。对于移位兼容头，重参数化不增加推理操作且保持打包 W4 执行，在 BF16 解码器下量化输出头使批量一生成延迟降低 10.8%。

[MOPD-Router](https://arxiv.org/abs/2609.30837) 重新思考多教师在线策略蒸馏（MOPD）中的路由机制，提出无需领域标签即可在 token 级别路由监督的框架。通过 ExpertAlign 指标评估各教师在当前 token 的修正是否表达了其事后训练获得的专门化能力，实验表明 ExpertAlign 在所有四种蒸馏设置（强到弱、同尺寸、标注/未标注数据）中表现最优。在未标注数据上，ExpertAlign 较平均聚合提升 5.88 点（+12.3%），在领域标注数据上较标准 MOPD 提升 3.95 点（+7.8%）且未使用可用领域标签。研究证明 token 级路由可开发跨领域互补监督信号并减少对提示级领域分配的唯一依赖。

## 个性化文本生成与界面

[CARD](https://arxiv.org/abs/2601.06352) 提出分层个性化文本生成框架，通过渐进式精炼平衡细粒度个性化与可扩展部署。首先根据共享风格模式对用户聚类并学习组级 LoRA 适配器，然后引入隐式偏好学习机制，通过对比用户 authored 文本与聚类级生成结果推断用户特定风格偏好，无需手动标注。推理时仅在解码阶段注入轻量级用户偏好向量和低秩 logit 修正，保持基础模型冻结。在 LaMP 和 LongLaMP 基准上的实验表明，CARD 在生成质量上优于基线，同时显著提升效率与可扩展性。

[PsPLUG](https://arxiv.org/abs/2601.06362) 发现显式风格指令与个性化之间存在冲突，将这种现象命名为个性化坍缩（personalization collapse）。提出的 PsPLUG 插件在学习请求风格后学习用户特定残差，允许在推理时调节个性化强度。实验表明，现有个性化方法在显式风格指令下会弱化用户特定特征，而 PsPLUG 在保持用户偏好的同时提供更精确的个性化与风格遵从平衡控制。

[BoundInk](https://arxiv.org/abs/2604.02103) 提出写作者条件化的在线手写生成框架，将字符间边界作为显式生成单元。通过联合建模局部过渡与周围文本上下文，在保持写作者特定字形外观的同时改善完整文本行的连接性和间距。引入的边界感知评估框架直接评估游笔连续性和字符间空间关系，而非仅依赖轨迹相似度。在三个基准匹配设置上，BoundInk 在所有适用的边界质量指标上均有改善，归一化动态时间规整降低 17.6%-47.8%，盲人评价中 78.0%-82.6% 的判定时优于对比方法。

## 视觉与空间理解

[TrackEverything](https://arxiv.org/abs/2609.30222) 提出打破稀疏点追踪与密集短片段追踪之间权衡的 3D 点追踪方法。通过将视频表示为世界坐标中的持久 3D 场景轨迹，模型复杂度与视频时长解耦，随物理场景几何扩展而非帧数扩展。核心创新包括滑动窗口边界的体素化去重机制、端点精炼器结合静态/动态分类与轻量轨迹精炼器、以及用高效场景云特征采样替代计算密集的 4D 相关性体积（3D WAFT）。在 TAPVid-3D 上，TrackEverything 在短片段上以超过 20% APD 超越所有开源全帧密集 3D 追踪器，同时在长序列上保持与最先进稀疏追踪器竞争力，且追踪点数远超稀疏方法，内存占用控制在 40GB 以内。

[Enhancing Photogrammetric DSMs](https://arxiv.org/abs/2609.31199) 研究结合摄影测量 DSM 与 Pléiades 影像的多模态条件扩散模型用于精炼数字表面模型。方法修改 Stable Diffusion 3 架构，采用剪枝文本流和逐块归一化策略，实现从自然图像到高程地图的稳定训练迁移。在法国城市的实验显示，多模态条件显著改善高程精度，密集城市 RMSE 从 6.00m 降至 3.45m（域内城市），从 4.16m 降至 2.77m（保留城市波尔多）。

[FoMo](https://arxiv.org/abs/2609.25716) 提出利用扩散模型生成动力学作为感知距离代理的图像质量评估方法。通过捕获生成早期（粗结构）与晚期（细细节）的分叉时刻，生成无标注的点式感知距离标签。该方法生成标签支持任意图像对间的通用比较，训练出的参考图像质量评估指标在多个基准上超越人工标注数据集。实验表明扩散轨迹与人类视觉系统对齐良好，FoMo 可作为参考锚定的距离标签有效监督基于参考的 IQA 指标训练。

## 代码理解与数据处理

[CodeGraph](https://arxiv.org/abs/2609.29474) 提出构建代码语义注解的知识图谱管道，使用代码专用大语言模型从 Stack-Edu 语料库的 1.67 亿文件中提取算法、范式、设计模式和应用域等概念实体。通过三阶段链接过程将实体锚定到 Wikidata：确定性 SPARQL 处理明确实体、Deep Research Agent 解决长尾实体、层次回卷导入父类闭包。最终构建的 CodeGraph 包含约 1.58 亿节点（1.45 亿文件、6.3 万概念实体、1.98 万 Wikidata 实体）和约 10 亿 typed 边，覆盖 14 种编程语言。引入的校准质量保证协议结合小规模人工金集与 LLM-as-a-judge 过滤器量化注解精度。

[RayOrch](https://arxiv.org/abs/2609.18703) 提出面向基础模型数据准备的谱系可控多粒度数据流编程模型与分布式执行引擎。系统通过声明有序变基数展开与匹配聚合操作保持父子关系贯穿执行全程，运行时记录子项成员、直接父项、不可变序数和终态。基于 FIFO Ready 队列跨父项批处理就绪子项，聚合操作从声明的成员和序数重建结果而非批边界。在 NVIDIA H20 GPU 上，RayOrch 在 MinerU 从 4 卡扩展到 64 卡时实现 15.14 倍加速，视频管道从 8 卡扩展到 64 卡时实现 7.82 倍加速，相比 Ray Data 将端到端时间减少 13.1%-16.0%。

## 领域特定应用

[IndicBankBench](https://arxiv.org/abs/2609.29167) 提出印度零售银行助手评估基准，包含 799 个案例覆盖五个运营域、能力/拒绝域和二十个主要轴。评估在四个阶段进行：安全性、行动与工具使用、响应充分性和咨询质量。通过 strict pass^3 指标（要求三次试验均成功）评估可靠性，结果显示严格可靠性范围 43.7%-58.2%，而至少一次成功范围 60%-74%，表明至少一次成功可能高估可靠银行行为。案例级诊断可区分提出不必要问题的系统与采取行动但未解决客户上下文的系统。

[ARGUS](https://arxiv.org/abs/2609.30867) 提出结构化的 LLM 管道审计气候政策因果评估中的识别假设。该方法基于十一维假设-含义-证据分类法评估报告证据，并在无法检索到相关证据时 abstain。在 11  flaw 基准上，ARGUS 检测出 73% 的植入缺陷，而关键词管道仅 18%。在 26 篇经济学论文上，ARGUS 因无法检索证据而对约 40% 的论文-维度评估 abstain。在五篇论文的小规模 pilot 中，ARGUS 在完成评估中有 25/33 项给出高于标签的风险等级。方法提供链接证据的风险报告以定位潜在弱点供专家审查，但不裁决因果主张。

[ZooWork-ShopRanker](https://arxiv.org/abs/2609.31002) 提出面向电商重排器的偏好对齐方法，使用多家族推理 LLM 面板作为偏好 oracle 标注训练对，引入位置去偏判断和一致等级。8B 旗舰模型通过蒸馏服务 4B 和 0.6B 高效模型。配套的 ShopRank-Bench 基准包含约 10,000 个私有流量偏好对，按 judge 家族一致等级分层。实验表明，对齐后的 8B 和 4B 模型显著优于最强开放重排器基线，各模型均显著优于未对齐基座，0.6B 模型在同类中表现最佳，增益在两种格式和 MTEB 基准上均保持。

## 基础机制与结构分析

[Paragraph Boundaries](https://arxiv.org/abs/2609.23551) 通过层级旋转位置编码（hRoPE）实验检验段落结构的压缩特征。在固定 token 序列下干预段落坐标并测量跨段落注意力，发现真实结构的判别信号是压缩深度而非压缩位置——控制实验（随机标签）也产生压缩但深度较浅且与语料无关。比较八个仅语料数量 across 三个结构构念（词汇持久性、段落长度、嵌入一致性），无一完全复现跨语料的深度排序，嵌入一致性最接近。分析表明压缩深度是层级文本结构的可复现签名。

[SAGE](https://arxiv.org/abs/2609.30192) 针对长程推理中的探索偏差与累积偏差，提出拓扑引导框架。通过符号闭包分析（SCA）刻画分支结构与稀疏奖励如何诱导偏差，随后采用代数稀疏化投影局部允许候选到算子索引代数子空间以抑制虚假分支，以及双曲结构引导将推理状态嵌入负曲率空间提供密集深度信号。在 12 个基准和 7 个模型家族上的实验显示，SAGE 在 Andrews-Curtis 问题（开放真实世界长程任务）上实现最高 8 倍提升，整体优于竞争性基线。

[SLCA-GRPO](https://arxiv.org/abs/2609.29050) 针对工具调用代理的跨段信用误分配问题，提出段锁定信用分配（SLCA）框架。通过 Schema-Guided LLM 模拟器（SGLS）实现可扩展探索，SLCA 在单次 rollout 组内解耦结构段的 Advantage 估计，配合分层奖励（HierR）将执行 Advantage 路由到工具 token、偏好 Advantage 路由到摘要 token。在 7B 骨干上的实验显示，SLCA-GRPO 加速收敛，在域内评估提升 2.53 点，BFCL 提升 1.36 点，τ²-Bench 提升 9.15 点，达到更高精度同时减少工具冗余与成本。

## 其他动态

[Jev 生态分析](https://arxiv.org/abs/2609.30216) 对 2,170 个公开 Jev 项目进行数据驱动分析，发现该决策模型在属性判断与评分方面应用广泛，而动作选择、内容过滤和模型/工具选择的使用则因领域而异。公众注意力集中于路由与接口代理，未与项目数量同步增长，表明 Jev 作为可复用决策组件的功能随工作流上下文变化。

[LightMIS](https://arxiv.org/abs/2609.28327) 提出无需分层解码器的超轻量医学图像分割网络，通过尺度对齐投影块对齐五层编码器输出并聚合，再通过自适应融合级联精化。全模型仅含 0.131M 参数和 0.575 GFLOPs，在 DRIVE、Kvasir-SEG 等数据集上达到 86.71% Dice 和 78.99% IoU，参数量较 Mobile U-ViT 减少 90.58%-99.61%，GFLOPs 减少 82.54%-96.14%，在 Arm Mali-G52 MC2 GPU 上可实现全 GPU 委派，中位延迟 53.31ms-138.31ms。
