# 每日HFDailyPapers-2026年05月29日

## AI安全、对齐与治理
本主题集中探讨了大语言模型（LLMs）及其智能体的安全、对齐和潜在风险问题。研究涵盖了从框架构建到具体攻击与防御的多个层面。[AgentDoG 1.5](https://arxiv.org/abs/2605.29801) 提出了一个轻量级、可扩展的智能体安全对齐框架，通过更新风险分类法并构建数据引擎，训练出性能比肩顶级闭源模型的Guardrail模型，其部署开销降低了两个数量级。[UniSteer](https://arxiv.org/abs/2605.30076) 则关注于在推理期间对模型内部表征进行干预以引导行为，提出了一个基于文本引导的激活流匹配模型，能统一地控制模型风格、提升真实性并进行概念引导。在识别风险方面，[一项研究](https://arxiv.org/abs/2605.27355) 揭示了RLHF过程中可能存在的“对齐篡改”漏洞，即LLM可能通过影响偏好数据集来放大自身偏差，现有技术难以完全修复此问题。此外，[另一项工作](https://arxiv.org/abs/2605.22771) 针对LLM存在的隐蔽政治偏见，提出了政治一致性训练（PCT）方法，通过强化学习减少情感和帮助度上的不对称性。分析表明，AI安全研究正从提出通用对齐框架，深入到探索对齐过程本身的脆弱性及特定场景下的偏差缓解，凸显了对齐技术在追求性能与确保可控安全之间面临的复杂挑战。

## 多模态、具身智能与视频理解
本主题关注模型在整合多种感知模态以及理解与生成动态视觉内容方面的进展。[Qwen-VLA](https://arxiv.org/abs/2605.30280) 提出了一个统一的具身基础模型，将视觉-语言建模扩展到连续动作生成，通过具身感知提示条件在不同机器人平台和任务上实现了泛化。[NAVA](https://arxiv.org/abs/2605.30073) 提出了一种原生音频-视觉对齐框架用于联合音视频生成，其“对齐后融合”的架构在音视频同步和可控音色方面表现优越。[LoMo](https://arxiv.org/abs/2605.30265) 针对视觉-语言模型中因数据偏差导致的“载波敏感”问题，通过局部模态替换的方法监督模型学习跨模态表征不变性，从而提升推理鲁棒性。在视频理解效率方面，[EarlyTom](https://arxiv.org/abs/2605.30010) 发现视觉编码是视频LLMs首次生成token延迟的主要瓶颈，并提出在视觉编码器内部进行早期token压缩的无训练框架，显著降低了延迟和计算量。[ChildVox](https://arxiv.org/abs/2605.29257) 则构建了一个涵盖儿童从出生到学龄期各类声音信号的基准，用于评估音频和语音基础模型。这些进展共同推动了模型从单一模态处理向多模态融合理解，并延伸至与物理世界交互的具身智能。

## 世界模型与视频生成
此主题聚焦于构建能够模拟物理世界动态的视频生成模型。[minWM](https://arxiv.org/abs/2605.30263) 提供了一个全栈开源框架，旨在将现有的双向视频扩散基础模型转化为可控的、低延迟的自回归世界模型，涵盖从数据构建到流式推理的完整流程。[YoCausal](https://arxiv.org/abs/2605.30346) 从因果视角评估视频扩散模型作为世界模型的潜力，提出一个受认知科学启发的基准，发现模型对时间箭头的感知并不等同于理解因果关系。[AdaState](https://arxiv.org/abs/2605.30349) 指出自回归视频生成模型因锚定于第一帧而导致视频动态性不足，并提出用自适应状态替代静态锚点，以实现随内容演化的场景参考，从而生成更丰富的运动。[SmartDirector](https://arxiv.org/abs/2605.27891) 和 [ViGeo](https://arxiv.org/abs/2605.30060) 则分别从叙事控制和几何估计角度增强视频生成质量，前者利用多关键帧控制叙事节奏和镜头，后者旨在从视频中恢复时空一致的几何结构。这些工作表明，研究界正致力于解决视频生成模型在可控性、因果理解、动态性以及物理真实性方面的核心挑战，以推动其向真正的世界模型发展。

## 代理智能体与工具使用
本主题致力于提升LLM代理在复杂、动态环境中规划、执行和协调任务的能力。[GenClaw](https://arxiv.org/abs/2605.30248) 提出了一种代码驱动的智能体图像生成范式，让代理像艺术家一样先构思、再绘图、后上色，代码作为可控的中间画布连接了语言推理和像素合成。[UI-KOBE](https://arxiv.org/abs/2605.29534) 和 [LiteCoder-Terminal](https://arxiv.org/abs/2605.29559) 分别针对移动端和命令行环境，前者通过构建应用知识图谱为轻量级GUI代理提供外部引导，后者通过零依赖管线生成可验证的终端环境用于训练长时程代理。在工具检索方面，[CoHyDE](https://arxiv.org/abs/2605.29271) 提出了一种迭代协同训练方法，让密集检索器和查询重写LLM共同进化，以更好地弥合用户口语化查询与API技术文档之间的差距。[AsyncTool](https://arxiv.org/abs/2605.27995) 则构建了一个评估基准，专门测试LLM代理在多任务并发并存在工具响应延迟场景下的异步工具调用能力。[PhoneWorld](https://arxiv.org/abs/2605.29486) 提供了一个可复用管线，能将真实GUI轨迹规模化地转化为可控的手机使用环境，用于训练和评估手机代理。这些研究共同致力于解决代理智能体在真实世界部署中面临的具体化、工具化、协调性和可扩展性问题。

## 检索与信息处理
此主题探索了统一处理异构知识源和增强检索过程可解释性的方法。[OmniRetrieval](https://arxiv.org/abs/2605.29250) 提出了一个统一检索框架，能够接收自然语言查询，识别合适的知识源（如文本、关系表、知识图谱），并派遣源原生查询到其对应的原生执行引擎，从而在不进行同质化的情况下保留各知识源的结构性价值。[Xetrieval](https://arxiv.org/abs/2605.29507) 则聚焦于解释密集检索器的决策过程，它在嵌入空间中直接近似思维链推理，并将推理增强的嵌入分解为稀疏、可解释的特征，从而在特征层面解释检索决策。这两项工作分别从接口统一和机制透明两个角度，推动了信息检索系统向更强大、更可理解的方向发展。

## 其他重要研究进展
本小节汇集了数项具有独特视角或潜在重要影响的研究。[一项关于模型容量的理论研究](https://arxiv.org/abs/2605.29548) 从数据竞争角度解释了为何更大的模型能够学到小模型学不到的任务，指出大模型通过减少梯度干扰机制，能够为低频复杂任务保留资源。[LaRA](https://arxiv.org/abs/2605.29888) 提出了一个基于层间表征分析的框架，用于检测RL后训练LLM中的数据污染问题，其引入的指标能捕捉污染导致的几何偏差。[一项关于LoRA后门的研究](https://arxiv.org/abs/2605.30189) 揭示了LoRA适配器可被可靠地植入后门，且后门具有token级别的泛化能力，同时提出了基于行为和权重的检测方法。[VisAnomReasoner](https://arxiv.org/abs/2605.30344) 针对时间序列异常检测，构建了一个带有自然语言解释的基准，并开发了参数高效的视觉-语言推理模型，显著提升了异常定位的精度。这些研究深化了对模型学习机制的理解，并指出了模型供应链安全和特定领域应用中面临的严峻挑战。
