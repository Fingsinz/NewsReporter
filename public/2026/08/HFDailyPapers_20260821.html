长上下文LLM推理优化

FlashPrefill V2 针对长上下文大语言模型推理中注意力机制的二次计算复杂度问题，将早期算法原型推进至生产可用版本。该方法引入均值修正项以抑制近似误差，采用 PackGQA 内存访问与 warp 特化设计重算稀疏注意力算子，并原生支持分页 KV cache 与连续批处理，可集成至 SGLang 等推理框架。在 NVIDIA H20 GPU 上的评估显示，FlashPrefill V2 在 128K 上下文长度下较 FlashAttention-2 获得最高 47.26 倍（FP8）和 27.19 倍（BF16）的加速，FP8 精度下相较对齐 FA3/4 的密集基线仍实现 30.49 倍加速。分析表明，稀疏注意力算子与现有 FlashAttention 实现的深度对齐，以及 FP8 推理的完整支持，标志着长上下文服务从研究原型向生产落地的关键进展。

智能体学习与技能进化

EnvHarness 提出一种可编程插件层，通过标准接口包装静态环境以重塑其行为，无需修改底层逻辑即可针对智能体弱点动态调整环境。配合自动化组件合成工具 EnvRigger，该方法在四个领域的五个基准上均优于原始环境和领域特定生成管线，在未见过实例上最高提升 9.0 分且执行步数减少 9.8%。SkillEvo 则针对智能体技能的持续进化问题，将多轮用户模拟重构为反馈生成机制，并引入独立的治理层主动修复事实退化与结构性膨胀。在九个生产技能上的评估显示，SkillEvo 超越自反思进化方法 23.0 分、超越单轮问答驱动的进化方法 15.4 分。两项研究共同指向智能体学习的关键趋势：从静态环境向动态自适应环境转变，以及从单轮反馈向多轮持续进化梯度的演进。

代码生成与科学软件工程

SWE-bench Science 构建了一个涵盖 20 个科学领域、119 个任务的仓库级基准，用于评估编码智能体在科学软件工程中的能力。即使是表现最佳的 Claude Code 与 Opus-5 (max) 组合，pass@1 仍低于 50%，研究识别出四类 recurring 失败机制：科学知识或抽象缺陷、探索方向偏差或表面修复、修复覆盖不完整或系统集成失败，以及科学知识泛化能力不足。Repo0 提出连续结构演化框架，通过显式架构状态（Dual-DAG）和模块性度量的引导迭代演化组件边界，最终实现结构收敛后指导测试驱动开发。在六个真实仓库上的评估显示，Repo0 相较最强基线 RPG，功能覆盖率最高提升 20.08 个百分点，通过率最高提升 29.74 个百分点。两项工作共同表明，代码生成正从单文件任务向仓库级架构感知与科学领域专业化方向演进。

文档知识内部化与检索自由问答

Inject, Align, Recover（IAR） 提出三阶段后训练框架，将固定语料库转化为检索自由的参数化知识。Inject 阶段将源文档转化为续写、改写和指令条件重建目标；Align 阶段通过仅答案的 QA 监督适配模型行为；Recover 阶段将领域适配模型与基础指令模型合并以恢复通用能力。在 Llama、Phi、Qwen 和 SmolLM 四个模型系列上的评估显示，IAR 在七个场景（共八个）中全面超越 vanilla SFT，领域 QA 准确率平均提升 3.6 个百分点，通用性能（IFEval、MMLU、MSBench）平均提升 12.1 个百分点。分析表明，分阶段训练策略有效缓解了传统继续预训练中领域知识注入与通用能力退化之间的固有矛盾。

视觉生成：4D重建与身份保持

4DAnyone 解决从单目视频重建 4D 人类的挑战，核心问题在于现有相机控制视频扩散模型在生成数十个目标视角时无法维持视图间一致性。研究将该失败归因为有界注意力上下文问题，并提出参考上下文打包（RCP）与目标上下文路由（TCR）两项设计分别解决 O(N) 参考上下文增长和跨组信息隔离两个瓶颈。WithEveryone 则聚焦群组图像生成中的身份保持问题，提出将身份注入为寻址 token、预测结构化身份-布局规划并将其渲染为视觉条件的统一框架。在身份不相交基准上，WithEveryone 将人脸相似度从 GPT-Image-2 的 0.462 提升至 0.499，复制粘贴伪影从 0.169 降至 0.055，并覆盖 97.3% 的指定身份且重复率仅 2.8%。两项工作分别针对 4D 重建的多视图一致性问题和群组生成的身份绑定问题提供了结构性解决方案。

EXIMO 针对 VLA 策略在新任务上的高效微调问题，提出探索-模仿-优化三阶段算法。探索阶段利用 VLM 作为规划器将长_horizon_任务分解为短任务并收集编排数据集；模仿阶段用编排数据微调 VLA；优化阶段通过残差离策略强化学习进一步微调。实验表明该方法在样本效率和最终性能上均显著优于现有方法。分析表明，将 VLM 的规划能力与 VLA 的执行能力分层结合，为大规模视觉语言动作模型的在线任务适应提供了可行的工程路径。

Chain-of-Experience 研究 LLM 在测试时通过迭代交互积累经验以实现持续改进的能力，在数学、编码和知识三个领域评估了八种模型。结果表明利用迭代经验持续优于无反馈基线，仅自反馈即可带来 5.6% 的整体提升和 19% 的 API 成本降低，而结合互补反馈通道（如模型反馈与正确性信号）可带来进一步增益。PolicyGuide 针对客服 LLM 智能体的政策合规问题，将领域政策编译为工作流图并在用户交互边界调用主动验证器，跨航空、零售和电信三个领域在 GPT-5.4 智能体上使平均 Pass^4 从 0.42 提升至 0.62，其中结构化程度最高的电信领域提升最大（0.19 至 0.61）。两项工作分别展现了测试时推理增强的潜力和多层工作流合规验证的工程有效性。

ForgeWM 提出渐进式因果训练框架，将双向动作条件视频生成器转化为高效少步世界模型，支持 1、2、4 步稳态去噪预算。方法包含领域适配、教师强制因果训练、因果一致性蒸馏和策略分布匹配四个阶段，并在 Minecraft 轨迹上以成像质量、动作信号准确率和鼠标控制准确率领先所评估系统。双路径部署协议允许一步学生模型在回放时重新去噪和精炼已保存草稿，达到接近四步参考质量的同时轨迹偏差显著降低。该方法同样适用于游戏手柄控制的 FPS 游戏场景，表明少步因果世界模型在交互式视频生成中的应用潜力。
